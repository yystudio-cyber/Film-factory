# 分镜放映室

工作台的新建影片表单接受剧本、制作要求、片名和时长。选填的「制片简报」可填写目标观众、传播目标和播放渠道。选用「全自动成片」可让工厂根据验收结果自行选片。选用「逐镜确认」可在候选片就绪时亲自选片。

提交后，在右侧「制作进度」点击「打开分镜放映室」。也可以直接访问服务地址下的 `/storyboard`，并在顶部切换影片。

## 查看全片节奏

1. 导演生成初稿后，放映室按分镜计划的 24 fps 时长排列镜头。上方时间码依次显示分、秒、帧。点击镜号、拖动播放进度或用「上一镜」「下一镜」定位。
2. 在「连续播放来源」选择「仅分镜与参考图」后点击「连续播放」。有首尾帧的镜头在前后半段分别显示对应的冻结素材；引用上一镜的镜头会使用已采用片段的末帧预览。暂无图像时，播放器按该镜时长显示标明「分镜占位」的文字板。点击参考图可查看实际图像。
3. 在执行单中核对摄影、美术、声音、剪辑方向和原文验收项。下方后期栏显示现场声、对白、旁白、字幕、定版和叠加图。每次进入下一镜时，旁边的执行单和当前时间码同步更新。

角色跨镜回归时，参考图区会列出本版本人物比对所用的角色名、来源片库 C 编号和具体指认帧。切换候选或草稿也会切换到该版本记录的参考图、执行单和后期要求。

## 看渲染和选片

| 播放来源 | 画面与用途 |
| --- | --- |
| 优先已采用片段 | 使用已采用片段，其次为可选候选或草稿。仍在等待渲染的镜头使用分镜与参考画面。 |
| 优先渲染草稿 | 使用已就绪的本镜动态草稿，缺少草稿时继续查找可用媒体。自动播放跳过已退回的草稿。 |
| 本镜预览来源 | 可手动指定需要检查的候选、草稿或参考图。选择全局播放来源会清除逐镜指定。 |
| 播放交付母版 | 全片验收通过并交付后出现，播放合成后的 1080p MP4，可听完整配乐与终混。 |

需要低分辨率动作预检时，在创建影片前勾选「正片前生成单阶段渲染草稿」。先在工作流接入页面绑定所用路线的单阶段草稿工作流。此开关会增加 GPU 渲染与视觉审查时间。草稿生成后，可在放映室检查其画面与审片状态。上游镜头因修改而失效时，放映室同步移除受影响的旧草稿。

逐镜确认模式在当前待选镜头提供「采用」按钮。选择候选后点击该按钮即提交，生产队列将继续。需要修改、停止、批量执行时使用右上角的「制作任务」。需要检查模型调用、渲染尝试、质量证据和 GPU 状态时打开「生产监视器」。
