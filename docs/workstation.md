# 绑定已有工作流

从所用 ComfyUI 的成功记录取得 T2V、I2V 和首尾帧（FLF）三路工作流，导出 API JSON。在本机逐路运行 `python film.py inspect path/to/graph.json`。核对正向文本、时长或帧数、随机种子、输出视频节点；图生视频另核对首帧，首尾帧另核对尾帧。正负提示词和实际模型参数沿用原图。

在工作台的 `/setup` 页面核对节点，或使用 `python film.py bind ROUTE GRAPH MAPPING`。三个 ROUTE 分别是 T2V、I2V、FLF。绑定按实际节点输入建立。双卡工作站配置目标是 1920×1088 生成，原生每镜 24×秒+1 帧，采用区间最多 8 秒，最终裁到 1920×1080。音轨应由原工作流的视频输出携带。

在 `/monitor` 检查服务、磁盘、GPU、队列和任务结果。使用自己的设备标识核对归属。独立显存按单卡计算。型号、端口和访问 URL 均以实际环境为准。
