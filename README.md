# Film Factory · 制片工厂

在 Windows 工作站输入剧本、制作要求和目标时长，使用现有 Qwen、ComfyUI/LTX 和 ACE-Step 生成镜头、检查候选、逐镜剪辑并交付 MP4。中文网页提供「全自动成片」和「逐镜确认」。主控使用 Python 标准库与 Pillow，模型继续运行在原服务进程中。

## 在你的工作站启动

1. 下载或克隆本仓库到 `D:\ai\Film-factory`，保留原来的 Studio Console。使用原启动方式运行 ComfyUI（8188、GPU1）。要配乐时，启动支持原生 REST API 的 ACE-Step（8002、GPU0）。
2. 在项目目录打开 PowerShell。运行以下命令，输入供现有 Qwen 接口使用的密钥。启动器首次运行会从示例创建本机配置；工作站需要 Python 3.12+、Pillow 以及 PATH 中的 ffmpeg、ffprobe。
3. 打开 <http://127.0.0.1:8766/setup>。分别从 ComfyUI 成功历史或 API JSON 导入三条已校准的**正片**工作流，确认动态输入和最终输出节点。节点号以本机图为准。绑定保存在本地，下次启动可直接生产。详见[接入与验收](docs/workstation.md)。

```powershell
cd D:\ai\Film-factory
$env:FILM_LLM_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'Qwen API Key' -AsSecureString)).Password
.\start.cmd
```

默认使用 `D:\ai\venv\Scripts\python.exe`。可通过 `FILM_PYTHON` 指定其他解释器。示例中的 Qwen URL 来自工作站说明；请使用已经验证可用的服务地址。首次配置如需修改 `config.local.json`，修改后重启控制台。剧本、制作要求、参考图及抽帧将发送到配置的 Qwen 端点，渲染素材及成片保存在 D 盘。

## 制作与交付

在首页填写片名、剧本、制作要求和目标秒数（2–600）。选择「全自动成片」后，合格候选自动进入下一镜。页面默认选择「逐镜确认」，可先看片，选中 C 编号后继续。一次可以提交多部影片，一台工作站同时制作一个任务。

| 阶段 | 实际处理 |
|---|---|
| 拆镜 | 整理角色、服装、时空、声音约定，保持对白与定版文字。按 2–8 秒设计镜头，优先 4–6 秒。超过 90 秒先拆成场次，再拆镜。总秒数与素材引用都要通过程序校验。 |
| 生成 | 写英文提示词，核对字数、Sound 段和原文台词。根据首尾帧选择 T2V、I2V 或 FLF。衔接镜头取上一条采用素材在剪辑点的干净尾帧。换场可指定独立参考图。 |
| 验收与返工 | 校验画幅、帧率、帧数、可解码性与所需音轨；有同期对白时进行本地语音回听比对。Qwen 根据五个时间点及参考图评价叙事、构图、身份、衔接和画面瑕疵。默认五项均 ≥4/5 才通过，每个候选最多生成 3 次。 |
| 剪辑与声音 | 精确裁切到 24 fps 时间线；1920×1088 居中裁成 1920×1080。标题及指定 PNG 后叠；保留现场声，按需加入 Windows 旁白与 ACE-Step 配乐。 |
| 交付 | 检查整片实际帧数、编码、解码与音画时长，把成片各镜的中点抽成联系表，结合原剧本与时间线做总审。总审定位到具体镜头时，默认允许一轮自动修订。 |

成功后可播放或下载 `film.mp4`、`timeline.json` 和 `acceptance.json`。需要进现有 FableCut 时可导出带片号的 1280×720 代理片、配乐及剪辑清单，命令见接入文档。工厂的时间线 JSON 是制作审计清单。

## 接回现有素材与片库

- 将 `assets` 配置指向素材目录，或将需要的 PNG/JPEG 放入默认的 `D:\ai\film-factory\assets`。同名 UTF-8 文本（例如 `杭州夜研.txt`）作为导演选图描述。可直接在制作要求中写参考素材文件名。
- 空库从 C001 开始。**要沿用原 Studio 的编号，请在首次生产前执行 `import-clips`**。导入清单明确指定素材及旧库曾发放的最大编号，包含已删除的号。之后可写「用 C001 的尾帧衔接 S02」。只使用独立新片库时，两边的 C 编号分别归各自片库管理。
- 每个候选拥有自己的目录、种子、图参数、抽帧、评分和媒体。重制已通过的镜头会重新验收它和后续镜头，保留旧候选及编号。
- 停止或进程异常中断后，已采用镜头保留，需要显式继续。停止调度不会向共享 ComfyUI 发全局中断；已提交的远程推理可能仍在运行。可在候选目录的 `remote.json` 中按任务 ID 核对。
